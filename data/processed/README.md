# Processed data
`antonym_axes.json` contains the WordNet antonym axes generated by
`scripts/build_antonym_axes.py`, with BabelDomains annotations.

`warmth_axes.json` and `competence_axes.json`: The Warmth and Competence axes which are generated by
  `scripts/build_scm_axes.py`.

  `probing_<template>_n<n>.json`: The probing datasets (template sentences for both poles of each
  semantic axis) which are generated by `scripts/build_probing_data.py`, with
  `template` = `listing` | `simple` and `n` = `15` | `30` sentences per pole.

  `eligible_pool.json`: The 1,114 semantic axes relevant to humans.
